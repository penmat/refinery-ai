# Monitor modernization scorecard

On a selected profile run, show starting and latest assessment scores out of
100, the date of the latest measurement, and the signed point change when
scoring profiles and assessed categories match. A single assessment supplies
the starting score; wait for a second distinct assessment before showing a
change. Keep absent scores distinct from zero. Expand the card for category
scores, point changes, coverage, and the largest remaining deductions.
Keep the label "Latest" after a run ends; the last assessment may precede
the final code change.

Record a bounded score summary on each completed Analyze journal event. This
keeps the card accurate during replay and independent of report files.
Reading assessment artifacts could backfill older runs but would depend on
those artifacts being present and matched to the correct Analyze visit.
Older journals without scores show an explicit unavailable state.
