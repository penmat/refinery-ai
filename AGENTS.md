# Agent instructions

This repository is part of the refinery-ai project.

## Development workflow

Use the Superpowers skills for all development work in this repository, including features, bug fixes, refactoring, and tests.

Before starting development, load and follow `superpowers:using-superpowers`. Use the available skill discovery mechanism to locate the installed skills and read their current instructions rather than relying on memory.

Follow the relevant Superpowers workflows for the task:

- Design new behavior with `superpowers:brainstorming` and plan multi-step implementation with `superpowers:writing-plans`.
- Investigate bugs and unexpected behavior with `superpowers:systematic-debugging`.
- Implement features and bug fixes with `superpowers:test-driven-development`.
- Execute an agreed plan with the applicable Superpowers execution workflow.
- Verify results with `superpowers:verification-before-completion` before claiming completion or passing checks.
- Use the applicable Superpowers review and branch completion workflows when reviewing or integrating changes.

Follow explicit user instructions and higher-priority environment instructions when they override a skill workflow. If a required skill is unavailable, explain the limitation before proceeding with development.
